# ۰۹ · راهنمای رابط کاربری

## ۱) ساختار کلی
```
┌── نوار بالا: نام اپ · وضعیت موتور · وضعیت لایو · منوی ⋮ ────────┐
├── محتوا (یکی از ۵ تب) ────────────────────────────────────────┤
├── نوار پایین: ۵ تب + نوار وضعیت (پیام‌ها، پیشرفت، خطای فید) ──┤
└───────────────────────────────────────────────────────────────┘
```
در حالت تمام‌صفحه (تب چارت) نوارهای بالا و پایین **شناور** و نیمه‌شفاف روی چارت قرار می‌گیرند.

## ۲) تب چارت
| دکمه | کار |
|---|---|
| `＋` / `−` | زوم پله‌ای (هم‌زمان زمان و قیمت) |
| `◀` / `▶` | جابه‌جایی به چپ/راست؛ `▶` از لبه ⇒ بازگشت به حالت زنده |
| `تنظیم نما` | چرخهٔ سریع: حجم ↔ باکس‌ها ↔ نشانگرها ↔ برچسب‌ها ↔ شبکه |
| `آخرین کندل` | پرش به آخرین کندل و فعال‌کردن دنبال‌کردن زنده |
| `⋮⋮` | منوی زمینه: تازه‌سازی، تنظیمات، گزارش، ذخیره |
| ردیف چیپ‌های تایم‌فریم | `1m 5m 15m 1h 4h 1D` — تغییر تایم‌فریم چارت (تجمیع داخلی) |
| خط راهنمای ژست‌ها | زیر نوار: «دو انگشت: زوم زمان و قیمت · یک انگشت: حرکت · نگه‌داشتن: کراس‌هیر · دو ضربه: بازگشت» |

زیر چارت (وقتی تمام‌صفحه نیست) پنل **رخدادها** می‌آید: آخرین ستاپ‌ها، سفارش‌ها و معامله‌ها با وضعیت و قیمت.

## ۳) تب سفارش‌ها
* جدول سفارش‌های لیمیت: جهت، قیمت، حجم، وضعیت (در انتظار / پر شده / لغو شده با دلیل / منقضی)،
  ستاپ مربوطه، کندل ثبت و کندل پر شدن.
* جدول معاملات بسته‌شده: ورود، خروج، دلیل خروج (`حد ضرر` / `خروج سر‌به‌سر` / `حد سود نهایی (1.272)`)،
  سود/زیان خالص، `R`، مدت معامله، کندل‌ها.
* ردیف‌های پوزیشن باز: TP1/TP2/TPX، پله‌های پرشده، وضعیت سر‌به‌سر.

## ۴) تب گزارش
* خلاصه: موجودی، سرمایهٔ اولیه، سود خالص، تعداد معاملات، نرخ برد، ضریب سود، میانگین R، بیشترین افت.
* جدول **دوره‌ای**: روزانه / هفتگی / ماهانه / سالانه (ستون‌ها: دوره، معاملات، برد، باخت، نرخ برد، خالص،
  ضریب سود، میانگین R، بیشترین افت).
* **منحنی سرمایه** با محور تاریخ (شمسی) و نقاط معاملات؛ با لمس هر نقطه، جزئیات آن معامله نمایش داده می‌شود.
* آمار موتور: ستاپ، برخورد، تایید میانی، ولوم کم، ولوم زیاد، ورود، پایان + تعداد باکس‌های ناحیه.
* دکمهٔ «ذخیرهٔ گزارش» → انتخاب مسیر و نوشتن فایل متنی.

## ۷) بنر هشدار داخل اپ
هر هشدار (اگر `banner` روشن باشد) به‌صورت نواری رنگی در بالای صفحه ظاهر می‌شود:
🟢 ورود/سود · 🔴 ضرر/لغو · 🟡 هشدار فید. با **لمس بنر** تاریخچهٔ ۲۰ هشدار آخر باز می‌شود.

تاریخ‌ها به‌صورت **شمسی** (`Fa.jalali` / `Fa.jalaliShort`) نشان داده می‌شوند.
