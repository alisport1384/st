# سناریوی ۱ — نزولی، با همهٔ استثناها، تا حد سود

فرض: چارت روی تایم‌فریم ۱ دقیقه است. ساختار = ۱۵ دقیقه، میانی = ۵ دقیقه، تریگر ۱ = ۳ دقیقه.

## گام ۰ — شروع کار

موتور از کندل‌های ۱ دقیقه‌ای، کندل‌های بزرگ‌تر می‌سازد. `Agg.step` از کامیت
`e137a05` به بعد شرط `periods >= 1` دارد — یعنی **اولین کندل کامل هر تایم‌فریم
هم پردازش می‌شود** و دور ریخته نمی‌شود. پیش از این کامیت این کندل‌ها از دست
می‌رفتند؛ الان رفع شده است.

## گام ۱ — هنوز روندی نیست

`trend = 0`. در این حالت `dirOK` همیشه `false` است، پس **هیچ ناحیهٔ فیکس‌رنجی ساخته
نمی‌شود**. موتور فقط کندل مهم می‌سازد و پین ثبت می‌کند.

## گام ۲ — اولین جفت

کندل ساختار `a` سبز است (`a.c > a.o`) و کندل `b` قرمز (`b.c < b.o`). این الگوی
**بالاترین‌ها** است.

کندل مهم = `pickHigh(a, b)` = آن که **سقف بزرگ‌تر** دارد. اگر سقف‌ها مساوی بودند، آن که
**کف بزرگ‌تر** دارد.

`ref = max(کلوز کندل مهم, اوپن کندل مهم)`:
* کندل مهم سبز بود ⇒ `ref = کلوز`
* کندل مهم قرمز بود ⇒ `ref = اوپن`

یک کاندید `BE` با `status = 0` ساخته می‌شود.

## گام ۳ — استثنا: کاندید می‌میرد

کندل ساختار بعدی می‌آید. `sb.c >= ref` است.

کاندید **می‌میرد** (`status = −1`) و دور انداخته می‌شود.

> ⚠ **فقط کلوز.** اگر کندل فقط با **باز** شدنش بالای `ref` برود ولی زیرش بسته شود،
> کاندید زنده می‌ماند. این در ۱٫۳٫۹ اصلاح شد.

جفت‌یابی از کندل بعدی دوباره شروع می‌شود.

## گام ۴ — اولین `pinBE`

یک جفت بالاترین‌ها زنده می‌ماند و کندل ساختار بعدی **زیر کف کندل مهم بسته می‌شود**
(`sb.c < imp.lo`) ⇒ **Ready BE**.

```
lastBEpin = سقف کندل مهم      beActive = true      beSeq = 1
highestBE = سقف کندل مهم      expectedReady = 1    pins.clear()
```

یک علامت «کندل مهم بالاترین · Ready BE · pinBE» روی سقف کندل مهم گذاشته می‌شود.

**روند هنوز `0` است.** `pinBE` به‌تنهایی روند نمی‌سازد.

## گام ۵ — استثنا: `pinBE` بی‌اعتبار می‌شود

`expectedReady = 1` یعنی نوبت `pinBU` است. در همین انتظار، کندل ساختار بعدی **باز**
می‌شود بالای `ref` (ولی زیر سقف کندل مهم بسته می‌شود).

شرط ابطال: `(sb.o > ref || sb.c > ref) && !(sb.c > lastBEpin)` ⇒ صادق است.

```
beActive = false
```

علامت «pinBE بی‌اعتبار شد» گذاشته می‌شود.

> ⚠ **`lastBEpin` پاک نمی‌شود.** سطح باقی می‌ماند. اگر بعداً روند نزولی شود، همین
> `pinBE` قدیمی نقش `LH` را برای تغییر روند بازی می‌کند.

## گام ۶ — `pinBU`

یک جفت پایین‌ترین‌ها پیدا می‌شود: کندل `a` قرمز، کندل `b` سبز.
کندل مهم = `pickLow` = کف **بزرگ‌تر** (تساوی ⇒ سقف کوچک‌تر).
`ref = min(کلوز کندل مهم, اوپن کندل مهم)`.

کندل ساختار بعدی **بالای سقف کندل مهم بسته می‌شود** ⇒ **Ready BU**.

```
lastBUpin = کف کندل مهم       buActive = true      buSeq = 2
lowestBUpin = کف کندل مهم     expectedReady = −1
```

## گام ۷ — روند نزولی تشکیل می‌شود

حالا هر دو پین وجود دارند. `trend == 0` و `sb.c < lastBUpin`:

```
trend = −1      LL = lastBUpin      LH = lastBEpin
```

علامت «روند نزولی تثبیت شد (توالی)».

## گام ۸ — ناحیهٔ فیکس‌رنج

حالا `dirOK` می‌تواند `true` شود: `trend == −1 && sb.c < sb.o`.

برای **هر کندل قرمز ساختار** یک پروفایل مستقل ساخته می‌شود، از کندل‌های ۱ دقیقه‌ای
داخل همان کندل ۱۵ دقیقه‌ای (`microS`).

پیمایش از **سقف به کف** (چون نزولی است). قله، بعد دره، بعد ناحیه. حداکثر دو ناحیه.
شرط اعتبار: `zBot > close`.

فرض کنیم ناحیهٔ **۲۶۴۰ تا ۲۶۴۸** ساخته شد ⇒ یک ستاپ با `stage = 0` و `dir = −1`.

## گام ۹ — برخورد

قیمت بالا می‌آید و وارد ۲۶۴۰–۲۶۴۸ می‌شود ⇒ `stage = 1`.
`touchMidStart` = زمان کندل ۵ دقیقه‌ای که الان باز است.

## گام ۱۰ — استثنا: تایید میانی باطل می‌شود

همان کندل ۵ دقیقه‌ای بسته می‌شود ⇒ `midRef = mc.h = ۲۶۴۵`، `stage = 2`.

کندل ۵ دقیقه‌ای بعدی مارک می‌شود (`stage = 3`).

اما کندل بعدی **یک تیک** بالای ۲۶۴۵ می‌رود و برمی‌گردد و زیرش بسته می‌شود.

با `midInvalidClose = false`، **همان عبور شمع کافی است** ⇒ تایید باطل.

```
midRef = NaN   lvBi = lvConfBi = hvBi = hvScanBi = −1
lvTouched = lvUsed = false    stage = 2
touchMidStart = زمان کندل ۵ دقیقه‌ای جاری
```

ستاپ **حذف نمی‌شود** — فقط به انتظار تایید تازه می‌رود.

## گام ۱۱ — تایید میانی دوباره

کندل ۵ دقیقه‌ای جاری بسته می‌شود ⇒ `midRef = ۲۶۴۶`، `stage = 2`.

## گام ۱۲ — استثنا: کندل ولوم کم باطل می‌شود

در تایم‌فریم ۳ دقیقه، کندلی با حجم کمتر از کندل قبلی‌اش پیدا می‌شود.
`lvH = ۲۶۴۷`، `lvL = ۲۶۴۳`.

کندل بعدی تا `lvL` بالا می‌رود (`q1.l <= lvL` نیست، ولی `q1.h >= lvH` است) ⇒ **`lvBi = −1`**.
کندل ولوم کم باطل شد و جست‌وجو از اول شروع می‌شود.

## گام ۱۳ — کندل ولوم کم تایید می‌شود

کندل ولوم کم تازه: `lvH = ۲۶۴۹`، `lvL = ۲۶۴۴`.

کندل بعدی **زیر ۲۶۴۴ بسته می‌شود** (`q1.c < lvL`) ⇒ **تایید**، `stage = 4`.

**باکس ولوم کم = ۲۶۴۴ تا ۲۶۴۹** — یعنی سقف و کف **خودِ کندل ولوم کم**. کندل
تاییدکننده نقشی در مرزها ندارد.

## گام ۱۴ — بازگشت به باکس

قیمت برمی‌گردد و به باکس برخورد می‌کند ⇒ `lvReEntered = true`، اسکن ولوم زیاد شروع می‌شود.

## گام ۱۵ — استثنا: کندل ولوم زیاد نقض می‌شود

کندلی با حجم بیشتر از کندل قبلی چارت پیدا می‌شود ⇒ `hvH = ۲۶۵۰`، `hvL = ۲۶۴۶`، `stage = 5`.

کندل بعدی تا `hvH` بالا می‌رود (`high >= hvH`) ⇒ **`hvBi = −1`**، `stage = 4`.
جست‌وجوی کندل ولوم زیاد از اول.

## گام ۱۶ — کندل ولوم زیاد تایید می‌شود ⇒ مسلح

کندل ولوم زیاد تازه: `hvH = ۲۶۵۱`، `hvL = ۲۶۴۷`.

کندل بعدی **زیر ۲۶۴۷ بسته می‌شود** (`close < hvL`) ⇒ **`armSetup`**.

با فرض `highestBE = ۲۶۵۱` و `midRef = ۲۶۴۶`:

| | |
|---|---|
| `a0` = `lowestBUpin` | ۲۶۱۰ |
| `a1` = `midRef` | ۲۶۴۶ |
| `R = a1 − a0` | ۳۶ |
| **ورود** = `hvL` | **۲۶۴۷** |
| **حد ضرر** = `hvH + 2 × mintick` | **۲۶۵۱٫۲** |
| **TP1** = `a1 − 0.382 R` | ۲۶۳۲٫۲ |
| **TP2** = `a1 − 0.5 R` | ۲۶۲۸ |
| **TPX** = `a1 − 1.272 R` | ۲۶۰۰٫۲ |

یک **سفارش لیمیت فروش** روی ۲۶۴۷ ثبت می‌شود. `stage = 6`.

> ⚠ اگر در این لحظه سفارش معلق یا معاملهٔ باز دیگری وجود داشته باشد، `registerLimit`
> **ثبت نمی‌کند**. در کد، هم‌زمان حداکثر یک سفارش ممکن است.

## گام ۱۷ — استثنا: سفارش منقضی می‌شود

اگر قیمت تا ۱۵۰ کندل به ۲۶۴۷ نرسد، سفارش با `CANCELLED_EXPIRED` لغو می‌شود.

در سناریوی ما قیمت زودتر برمی‌گردد.

## گام ۱۸ — پر شدن و مدیریت

قیمت به ۲۶۴۷ می‌رسد ⇒ سفارش پر می‌شود، `stage = 7`.

ترتیب بررسی در **هر کندل** ثابت است: **حد ضرر → حد سود نهایی → TP1 → TP2**.

* به **۲۶۳۲٫۲** می‌رسد ⇒ ۳۳٪ بسته می‌شود، `be = true`، حد ضرر مؤثر می‌رود روی **۲۶۴۷**
* به **۲۶۲۸** می‌رسد ⇒ ۳۳٪ دیگر بسته می‌شود
* به **۲۶۰۰٫۲** می‌رسد ⇒ ۳۴٪ باقی‌مانده بسته می‌شود

`stage = 8`، یادداشت «حد سود نهایی (۱٫۲۷۲)».

## گام ۱۹ — استثنا: تغییر روند در حین معامله

فرض کنیم وسط معامله، کندل ساختاری بالای `lastBEpin` بسته شود و `buSeq > beSeq` باشد
⇒ روند به **صعودی** چرخش می‌کند.

`cancelDir(−1)` صدا زده می‌شود، ولی فقط ستاپ‌های `stage < 7` را لغو می‌کند. **معاملهٔ
بازِ ما `stage = 7` است، پس دست‌نخورده می‌ماند** و تا حد سود یا حد ضرر خودش می‌رود.

# سناریوی ۲ — صعودی، همان جزئیات، یک سفارش سودده

قرینهٔ کامل. تفاوت‌های کلیدی:

## گام ۰ تا ۱ — همان

موتور از اولین کندل کامل هر تایم‌فریم شروع به کار می‌کند (رفع شد در `e137a05`).
`trend = 0` ⇒ هیچ ناحیه‌ای ساخته نمی‌شود.

## گام ۲ تا ۶ — توالی

* **پایین‌ترین‌ها:** کندل `a` قرمز، کندل `b` سبز. کندل مهم = کف **بزرگ‌تر**.
  `ref = min(کلوز کندل مهم, اوپن کندل مهم)`.
* Ready BU وقتی که کندل ساختار **بالای سقف کندل مهم بسته شود**.
* **بالاترین‌ها:** کندل `a` سبز، کندل `b` قرمز. کندل مهم = سقف **بزرگ‌تر**.
  Ready BE وقتی که کندل ساختار **زیر کف کندل مهم بسته شود**.

**استثنای ابطال `pinBU`:** اگر باز **یا** کلوز زیر `ref` برود، ولی کلوز زیر کف کندل مهم
بسته نشود ⇒ `buActive = false`، ولی `lastBUpin` باقی می‌ماند.

## گام ۷ — روند صعودی

هر دو پین موجود و `sb.c > lastBEpin`:

```
trend = 1      HH = lastBEpin      HL = lastBUpin
```

## گام ۸ — ناحیه

`dirOK = (trend == 1 && sb.c > sb.o)` — یعنی **کندل سبز ساختار**.
پیمایش از **کف به سقف**. شرط اعتبار: `zTop < close`.

فرض: ناحیهٔ **۲۶۰۰ تا ۲۶۰۸**.

**استثنای ردیف نخست:** اگر ردیفِ کف بزرگ‌تر از ردیف بعدی‌اش باشد، **کف کندل** شروع
ناحیه می‌شود.

## گام ۹ تا ۱۳ — تایید میانی و ولوم کم

قرینه:
* `midRef = mc.l` (کف کندل میانی) — فرض **۲۶۰۴**
* ابطال با **عبور شمع زیر ۲۶۰۴**، حتی یک تیک
* ابطال کندل ولوم کم: `q1.l <= lvL`
* تایید کندل ولوم کم: `q1.c > lvH`
* باکس = سقف و کف **خودِ کندل ولوم کم**، فرض **۲۶۰۲ تا ۲۶۰۵**

**استثنای یک‌بارمصرف:** اگر قیمت داخل باکس برود و بعد **بالای `lvH` بسته شود**، باکس
مصرف شده. اگر هنوز معامله‌ای نشده باشد، ستاپ به ۸ می‌رود.

## گام ۱۴ تا ۱۶ — ولوم زیاد و مسلح شدن

* ابطال کندل ولوم زیاد: `low <= hvL`
* تایید: `close > hvH`
* کندل ولوم زیاد فرض: `hvH = ۲۶۰۹`، `hvL = ۲۶۰۳`

با `highestBE = ۲۶۵۰` و `midRef = ۲۶۰۴`:

| | |
|---|---|
| `a0` = `highestBE` | ۲۶۵۰ |
| `a1` = `midRef` | ۲۶۰۴ |
| `R = a0 − a1` | ۴۶ |
| **ورود** = `hvH` | **۲۶۰۹** |
| **حد ضرر** = `hvL − 2 × mintick` | **۲۶۰۲٫۸** |
| **TP1** = `a1 + 0.382 R` | ۲۶۲۱٫۶ |
| **TP2** = `a1 + 0.5 R` | ۲۶۲۷ |
| **TPX** = `a1 + 1.272 R` | ۲۶۶۲٫۵ |

**سفارش لیمیت خرید** روی ۲۶۰۹.

**استثنا:** اگر بعد از مسلح شدن، کندلی **زیر `hvL` بسته شود** ⇒ ناحیهٔ ولوم زیاد نقض
شد، `hvBi = −1`، `stage = 4` — یعنی دوباره به دنبال کندل ولوم زیاد می‌گردد.

## گام ۱۷ تا ۱۸ — پر شدن و سود

قیمت برمی‌گردد به ۲۶۰۹ ⇒ پر می‌شود، `stage = 7`.

* **۲۶۲۱٫۶** ⇒ ۳۳٪ بسته، `be = true`، حد ضرر مؤثر = **۲۶۰۹**
* **۲۶۲۷** ⇒ ۳۳٪ بسته
* **۲۶۶۲٫۵** ⇒ ۳۴٪ بسته، «حد سود نهایی (۱٫۲۷۲)»
