## ۲) تب چارت (پیش‌فرض = مود ساختار ۱ ساعته)

* **چارت روی تایم‌فریم تریگر ۲** اجرا می‌شود؛ تایم‌فریم‌های بالاتر داخل خود موتور تجمیع می‌شوند
  (بدون `request.security` و بدون ریپینت).
* **پنج مود تایم‌فریمی** با پیش‌فرض مود ۱ (۱ ساعته / ۱۵ دقیقه / ۵ دقیقه / ۱ دقیقه). مود ۵ دلخواه است.
* چه چیزهایی روی چارت دیده می‌شود:
  * کندل‌ها + حجم در نوار پایین
  * **باکس‌های ناحیهٔ فیکس‌رنج**: زنده (رنگ‌دار با برچسب Z۱/Z۲) · پاک‌شده با کلوز از سمت دور (خاکستری کم‌رنگ) ·
    **ردشده** (خط‌چین خاکستری) · سبزآبی = ناحیهٔ صعودی، نارنجی = نزولی
  * برچسب‌های استراتژی: کندل مهم / Ready BU / pinBE / تایید میانی / ناحیهٔ ولوم کم / کندل ولوم زیاد / مسلح / ورود / خروج
  * خطوط معامله: ورود (سبز) · حدضرر (سرخ) · TP1/TP2 (نارنجی) · حدسود ۱٫۲۷۲ (بنفش)
  * POC به‌صورت خط‌چین طلایی (فقط برای مقایسه با ابزار TradingView — **در ساخت ناحیه‌ها نقشی ندارد**)
* **ژست‌ها (مثل TradingView):**
  * دو انگشت افقی → زوم و فشرده‌سازی کندل‌ها
  * دو انگشت عمودی → مقیاس قیمت
  * یک انگشت → جابه‌جایی
  * دو بار ضربه → بازنشانی نما
  * نگه‌داشتن انگشت → کراس‌هیر با قیمت و زمان
  * دستهٔ «⋮⋮ کشیدن برای تغییر اندازهٔ چارت» → کوچک/بزرگ کردن ارتفاع چارت
* دکمه‌های بالا: `＋` `−` `تنظیم نما` `حجم` `باکس‌ها` `برچسب‌ها`.
* زیر چارت: نوار انتخاب تایم‌فریم چارت + **گزارش رویدادهای موتور** (ستاپ جدید، مسلح شدن، ورود، لغو…).

## ۳) تب سفارش‌ها

هر سفارش ثبت‌شده با تمام جزئیات: نوع (خرید/فروش لیمیت کاغذی)، قیمت، حدضرر، TP1/TP2/TP نهایی، حجم،
بازهٔ ناحیهٔ ساختار، زمان ثبت، زمان پر شدن، وضعیت (در انتظار / پر شده / منقضی / لغو + دلیل).
روی هر ردیف بزنید تا پنجرهٔ جزئیات باز شود. پایین همان صفحه، فهرست معاملات است.

**نکته:** سفارش ورود روی لبهٔ ناحیهٔ ولوم زیاد (تریگر ۲) ثبت می‌شود و اگر تا `حداکثر کندل برای پر شدن`
(پیش‌فرض ۱۵۰ کندل) پر نشود، خودکار لغو می‌شود.

## ۴) تب سود و زیان

* خلاصه: سود/زیان خالص، تعداد معاملات، برد/باخت، نرخ برد، ضریب سود، میانگین R، بیشترین افت سرمایه، موجودی نهایی.
* **نمودار منحنی سرمایه با تاریخ شمسی روی محور افقی** — زوم دو‌انگشتی و کشیدن دارد؛ روی هر نقطه بزنید تا
  جزئیات همان معامله باز شود.
* فهرست معاملات: کلیک = جزئیات کامل (ورود/خروج، قیمت‌ها، حجم، **پله‌های اجرا ۳۳٪/۳۳٪/۳۴٪**، دلیل خروج، R، مدت).

خروج پله‌ای دقیقاً مثل استراتژی: TP1 (۳۸٪) → انتقال حدضرر به سر‌به‌سر → TP2 (۵۰٪) → حدسود نهایی (۱٫۲۷۲).

## ۷) ذخیره و بازیابی — «دقیقاً همان چیز برگردد»

هر بار بستن اپ و هر ۲ دقیقه در حالت لایو، یک **فایل وضعیت** ذخیره می‌شود (پیش‌فرض:
`Android/data/com.alisport.goldpin/files/goldpin_state.json.gz`). این فایل شامل:

* همهٔ کندل‌ها
* **همهٔ باکس‌های ناحیه، حتی آن‌هایی که با گذشت زمان پاک شده‌اند** (با وضعیت و کندلِ پایان) → پس از بازیابی،
  دقیقاً همان‌طور که بودند (خط‌چین خاکستری) برمی‌گردند
* **همهٔ سفارش‌ها** با وضعیت نهایی‌شان (لغو‌شده/منقضی/پر‌شده)
* همهٔ معاملات با ریز پله‌ها، سود/زیان و موجودی
* وضعیت کامل موتور: روند، HH/HL/LL/LH، کاندیدهای کندل مهم، ستاپ‌های نیمه‌کاره با تمام سطوح و مرحلهشان

با «ذخیره در فایل…» میتوانید نسخهٔ خود را هر جا (حافظهٔ داخلی، کارت حافظه، درایو ابری) نگه دارید و
با «بازیابی از فایل…» همان وضعیت را عیناً برگردانید. این قابلیت با آزمون خودکار سنجیده شده است
(`StoreTest`: ذخیره → بازیابی → ادامهٔ اجرا → مقایسهٔ تک‌تک معاملات و باکس‌ها).

## ۸) تست زنده (لایو کاغذی)

* دکمهٔ **«لایو»** در بالای صفحه → سرویس پیش‌زمینه با نوتیفیکیشن وضعیت روشن می‌شود.
* هر چند ثانیه (قابل تنظیم، پیش‌فرض ۱۰ ثانیه) دنبالهٔ داده به‌روز می‌شود؛ **قیمت زنده** از سه منبع
  (gold-api → Swissquote → CoinGecko) گرفته می‌شود.
* موتور **فقط کندل‌های بسته** را پردازش می‌کند (بدون ریپینت) اما سفارش لیمیت همان لحظه که قیمت به آن برسد
  پر می‌شود — مثل کارگزار واقعی. بنابراین «ارزیابی دائمی» با «دقت» جمع شده است.
* در نوتیفیکیشن: قیمت، روند، سفارش در انتظار، سود/زیان پوزیشن باز.
* معاملات **کاغذی** است؛ به هیچ کارگزاری وصل نمی‌شود و سفارش واقعی ارسال نمی‌کند.

## ۱۱) ساخت مجدد از سورس

```bash
git clone https://github.com/alisport1384/st.git && cd st
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk     # platform 34 + build-tools 34
./gradlew :app:assembleRelease               # → app/build/outputs/apk/release/app-release.apk
./gradlew :engine:test :app:testReleaseUnitTest   # آزمون‌ها
```

اگر مخزن گیت‌هاب هنوز سورس را ندارد، از باندل محلی استفاده کنید:

```bash
git clone goldpin_v1_repo.bundle st && cd st
git remote set-url origin https://github.com/alisport1384/st.git
git push -u origin main      # یا: git push -u origin master
```
