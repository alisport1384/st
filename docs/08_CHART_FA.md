# ۰۸ · چارت: رفتار TradingView و ژست‌ها

## ۱) قانون پروژه
چارت باید **همان‌طور که در TradingView با انگشت کار می‌کنید** کار کند و **تمام‌صفحه** باشد؛
کاربر گفت: «چارت مثل تریدینگ ویو باشد، با دو انگشت زوم شود و تمام‌صفحه باشد.»
(تحقیق انجام‌شده: مستندات رسمی TradingView Charting Library بخش mobile_specifics + راهنماهای موبایل
TradingView؛ نتیجه: پینچ روی موبایل **هم‌زمان زمان و قیمت** را زوم می‌کند، کشیدن روی محور قیمت
زوم عمودی مستقل می‌دهد، دو ضربه روی محور = بازگشت به مقیاس خودکار، کشیدن یک‌انگشتی = جابه‌جایی.)

## ۲) جدول ژست‌ها (پیاده‌شده)
| ژست | کار | جزئیات فنی |
|---|---|---|
| **دو انگشت باز/بسته (پینچ)** | زوم هم‌زمان زمان **و** قیمت | لنگر زوم روی «نقطهٔ میانی دو انگشت» است؛ همان کندل/قیمتی که زیر انگشت‌هاست ثابت می‌ماند |
| دو انگشت جابه‌جایی | جابه‌جایی هم‌زمان افقی+عمودی | تغییر مرکز با حفظ فاصلهٔ انگشت‌ها |
| یک انگشت بکش | جابه‌جایی زمان (و قیمت اگر مقیاس دستی باشد) | اسکرول نرم با شتاب (fling) |
| یک انگشت روی محور قیمت | زوم/جابه‌جایی عمودی مستقل | کشیدن ⇐ مقیاس دستی می‌شود |
| یک انگشت روی محور زمان | جابه‌جایی سریع زمان | — |
| **دو ضربه روی چارت** | بازگشت کامل نما (تحلیل خودکار + دنبال‌کردن لایو) | `resetView()` |
| **دو ضربه روی محور قیمت** | بازگشت مقیاس قیمت به خودکار | `resetPrice()` |
| **نگه‌داشتن (Long press)** | کراس‌هیر + منوی زمینه (افزودن به علاقه/تازه‌سازی/تنظیمات نما) | `onContextMenu` |
| کشیدن «▲▼» در نوار بالا | زوم پله‌ای / جابه‌جایی با دکمه | `zoomIn/zoomOut/scrollByBars` |

> نکته: زوم پینچ **همیشه** مقیاس خودکار قیمت را خاموش می‌کند (`autoPrice = false`) چون کاربر دارد
> خودش زوم قیمت را تعیین می‌کند؛ با دو ضربه روی محور قیمت، مقیاس خودکار برمی‌گردد.

## ۳) حالت تمام‌صفحه
* ورود خودکار به تمام‌صفحه وقتی وارد تب چارت می‌شوید (تنظیم `auto_fullscreen`، پیش‌فرض روشن).
* در تمام‌صفحه، نوار بالا/پایین **شناور** روی چارت می‌آیند تا ابعاد چارت کم نشود.
* دکمهٔ **BACK**: اول از تمام‌صفحه بیرون می‌آید، بار دوم از اپ خارج می‌شود.
* `FLAG_KEEP_SCREEN_ON` روشن است تا در حال تماشای چارت صفحه خاموش نشود.
* پیاده‌سازی: `WindowInsetsController.hide(systemBars())` برای اندروید ۱۱+ و
  `SYSTEM_UI_FLAG_IMMERSIVE_STICKY | FULLSCREEN | HIDE_NAVIGATION | LAYOUT_*` برای قدیمی‌تر.

## ۴) آنچه رسم می‌شود (لایه‌به‌لایه)
1. **شبکه** افقی/عمودی (سبک) + خط قیمت آخر
2. **کندل‌ها** (توپر و توخالی مطابق جهت) با ضخامت خودکار بر اساس `barW`
3. **پنل حجم** پایین چارت (%۲۰ ارتفاع) با رنگ سبز/سرخ
4. **باکس‌های ناحیه**: فعال (رنگ جهت‌دار + برچسب `Z1/Z2`) · پاک‌شده (خاکستری از زمان ساخت تا شکست) · ردشده (خط‌چین خاکستری)
5. **خطوط ولوم کم/زیاد** (طلایی/آبی) روی کندل‌های مارک‌شده
6. **خطوط معامله**: ورود (سبز)، حدضرر (سرخ)، TP1/TP2 (نارنجی)، TPX (بنفش) + ناحیهٔ سایهٔ ریسک/ریوارد
7. **نشانگرهای ستاپ** (Candle markers) با متن کوتاه مرحله
8. **کراس‌هیر + برچسب قیمت/زمان** در حالت نگه‌داشتن
9. **لِجِند** بالا-چپ (نام نماد، تایم‌فریم، قیمت، منبع داده) و **واترمارک** مرکزی
10. **برچسب قیمت آخر** روی محور قیمت + ضربان زنده (`livePulse`) وقتی کندل لایو به‌روز می‌شود

## ۵) مشخصات فنی
```kotlin
class ChartView(...) : View {
    // داده
    var candles: List<Candle>          // کامل
    var zones: List<ZoneBox>
    var markers: List<Marker>
    var overlays: List<SetupOverlay>   // خطوط/باکس‌های ستاپ فعال
    var trades: List<Trade>            // برای نمایش خطوط معامله‌های انجام‌شده
    // نمایش
    var showVolume/showZones/showMarkers/showGrid/showTradeLines/showWatermark/showLegend = true
    var livePulse = false
    // نما
    fun zoomBoth(factor, focusX, focusY)   // پینچ
    fun zoomTime(factor, focusX)
    fun panPixels(dx, dy)
    fun resetView() ; fun resetPrice() ; fun goLive()
    fun zoomIn() ; fun zoomOut() ; fun scrollByBars(bars)
    fun xOf(index) / indexAtX(x) / yOf(price) / priceAtY(y)
}
```
* مختصات با `Float` (dp→px) محاسبه می‌شوند؛ هیچ ابزار بیرونی رسم استفاده نمی‌شود.
* `rightIdx` شاخص آخرین کندل قابل‌نمایش و `barW` عرض کندل است؛ ژست‌ها فقط این دو (+`priceCenter`,`priceSpan`) را تغییر می‌دهند.
* وقتی `followLive = true`، `rightIdx` همیشه به آخرین کندل چسبیده است.
* بازهٔ زوم زمان: حداقل `0.6px` تا حداکثر `80px` عرض کندل (برای دیدن ۱ کندل یا ۴۰۰ کندل).
* بازهٔ زوم قیمت: حداقل ۰٫۲ و حداکثر ۲۰ برابر دامنهٔ خودکار.

## ۶) هم‌خوانی با موتور
* تایم‌فریم چارت = تریگر ۲. با تغییر تایم‌فریم چارت، داده دوباره تجمیع و موتور بازاجرا می‌شود
  (`AppState.changeChartTf`) و از همان ابتدا تا انتها محاسبه می‌شود — دقیقاً مثل اسکریپت Pine.
* همهٔ باکس‌ها و نشانگرهای چارت از خودِ موتور می‌آیند (`engine.zones`, `engine.setups`, `broker.orders/trades`)،
  پس آنچه می‌بینید با آنچه موتور محاسبه کرده یکی است.
