## بیلد
| نشانه | علت | درمان |
|---|---|---|
| `Inconsistent JVM-target compatibility` | `jvmToolchain(17)` حذف شده | در `engine/build.gradle.kts` نگهش دارید (`jvmToolchain(17)` + Java 11 + `jvmTarget "11"`) |
| `SDK location not found` | `local.properties` نیست | `sdk.dir=/home/USER/android-sdk` بسازید |
| Gradle OOM / کندی شدید | رم کم | swap ۶GB + `org.gradle.jvmargs=-Xmx1200m -XX:MaxMetaspaceSize=384m` |
| `Could not resolve com.android.tools.build:gradle:8.5.2` | اینترنت/کش خالی | یک بار با شبکه اجرا کنید؛ کش‌ها در `~/.gradle` ساخته می‌شوند |
| خطای بی‌پیام از gradle (کد خروج ۲۵۵) | دیمن خراب | `pkill -f "[G]radleDaemon"` سپس اجرای دوباره (توجه: الگو را داخل براکت بگذارید تا خودِ دستور kill نشود) |
