# ۰۰ · نمای کلی پروژه

## این پروژه چیست؟
**GoldPin** یک اپلیکیشن اندروید برای **طلا (XAUUSD)** است که استراتژی شخصی «PinReady» را
به‌صورت کامل پیاده می‌کند:

* **چارت‌کشی حرفه‌ای** با رفتار مشابه TradingView (پینچ، زوم، مقیاس خودکار، تمام‌صفحه)
* **بک‌تست** روی تاریخچهٔ واقعی طلا که خودِ اپ دانلود می‌کند
* **تست زندهٔ کاغذی (Paper)** با ارزیابی دائمی شرایط و ثبت خودکار سفارش‌ها
* **ثبت کامل** سفارش‌ها، معاملات، پله‌های خروج، سود/زیان و گزارش‌های دوره‌ای
* **ذخیره/بازیابی دقیق** به‌گونه‌ای که همه‌چیز (حتی باکس‌های پاک‌شده و سفارش‌های قدیمی) عیناً برگردد
* **لاگر کامل** (خروجی `.md` و `.txt`) و **سیستم هشدار/نوتیفیکیشن** برای لحظه‌های مهم

## دامنه (تصمیم‌های کلان)
| موضوع | تصمیم |
|---|---|
| دارایی | فقط طلا (نماد پیش‌فرض `GC=F` برای کندل، `XAU` برای قیمت لحظه‌ای) |
| اجرای واقعی | ندارد — معاملات **کاغذی** است؛ اتصال به کارگزار در برنامهٔ بعدی است |
| سرور | ندارد — همهٔ محاسبات داخل گوشی، بدون نیاز به کلید API |
| تایم‌فریم | چارت روی **تریگر ۲** اجرا می‌شود؛ تایم‌فریم‌های بالاتر داخل موتور تجمیع می‌شوند (بدون `request.security` و بدون ریپینت) |
| مود پیش‌فرض | **مود ۱: ساختار ۱ ساعته** (۱H / 15m / 5m / 1m) |
| زبان رابط و مستندات | فارسی |
| حداقل اندروید | API 24 (اندروید ۷) — هدف: API 34 |
| وابستگی خارجی | **هیچ** (بدون AndroidX، بدون کتابخانهٔ چارت، بدون JSON گاه بیرونی) |

## چرا بدون وابستگی؟ 
برای اینکه بیلد در هر محیطی (از جمله محیط ایجنت) سریع و قطعی باشد، APK کوچک بماند (≈۱٫۴ مگابایت)
و هیچ ریسک ناسازگاری نسخه‌ای وجود نداشته باشد. JSON، لاگر، چارت و ذخیره‌سازی همه دست‌ساز هستند.

## معماری در یک نگاه
```
┌────────────────────────────── app (اندروید) ─────────────────────────────┐
│ MainActivity (۵ تب)   ChartView   EquityChartView   Ui/Palette/Fa        │
│ AppState ── فید (Feed) ── ذخیره‌سازی (Storage) ── EngineService (لایو)    │
│ util/Log (لاگر)            util/Alerts (هشدار و نوتیفیکیشن)              │
└───────────────────────────────┬──────────────────────────────────────────┘
                                │ قلاب‌های logSink / alertSink / barCommitHook
┌───────────────────────────────▼──── engine (Kotlin خالص) ────────────────┐
│ Engine (چهار موتور)  VolumeProfile (الگوریتم v2)  PaperBroker  Reports   │
│ Store/Json (ذخیرهٔ دقیق وضعیت)   Types (Candle/Agg/Zone/Setup/Order/...) │
└──────────────────────────────────────────────────────────────────────────┘
                                ▲
                        cli (بک‌تست روی CSV)
```
`engine` هیچ وابستگی اندرویدی ندارد؛ به همین دلیل روی JVM هم تست و هم اجرا می‌شود (ابزار `cli`).

## نقشهٔ فایل‌های مهم
| مسیر | نقش |
|---|---|
| `engine/src/main/kotlin/com/alisport/goldpin/core/Engine.kt` | موتور اصلی (ساختار، میانی، تریگر۱، تریگر۲) |
| `engine/.../VolumeProfile.kt` | پروفایل حجم + **الگوریتم ناحیهٔ v2** |
| `engine/.../PaperBroker.kt` | کارگزار کاغذی: سفارش، پر شدن، پله‌های خروج، سر‌به‌سر |
| `engine/.../Store.kt` + `Json.kt` | ذخیره/بازیابی کامل وضعیت |
| `engine/.../Reports.kt` | گزارش روزانه/هفتگی/ماهانه/سالانه + منحنی سرمایه |
| `app/.../AppState.kt` | وضعیت سراسری، فید، جفت‌سازی لاگر/هشدار با موتور |
| `app/.../ui/ChartView.kt` | چارت با ژست‌های TradingView |
| `app/.../util/Log.kt` | لاگر (`md` + `txt`) |
| `app/.../util/Alerts.kt` | هشدار/نوتیفیکیشن |
| `app/.../svc/EngineService.kt` | سرویس پیش‌زمینهٔ ارزیابی زنده |
| `app/.../MainActivity.kt` | رابط کاربری (۵ تب + تمام‌صفحه) |
| `docs/` | همین مستندات |
